# Submission Draft

## Title

HyperLoom on a Radeon AI PRO R9700: Local Agentic Inference Evidence and Reproducibility

## Short Description

This project demonstrates a local-first agentic inference experiment on an AMD Radeon AI PRO R9700 workstation GPU. It connects a resident ROCm 10/vLLM/Qwen server to Hyperloom/KernelForge through a bounded OpenAI-compatible backend, captures repeatable evidence, and separates real serving/concurrency gains from unproven kernel optimization claims.

## What It Shows

- Local AMD hardware running an AI coding/planning model.
- Bounded tool use with no arbitrary shell.
- Baseline and candidate benchmarking.
- Deterministic KEEP/REJECT gates.
- Machine-readable launch manifest and evidence hashes.
- A small, reviewable upstream path for RDNA4/R9700 reproducibility.
